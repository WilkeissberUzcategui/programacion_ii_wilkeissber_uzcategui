# Programación II

Repositorio correspondiente a la asignatura **Programación II**.

En este repositorio se almacenarán proyectos, prácticas, ejercicios y subproyectos desarrollados durante el curso, utilizando principalmente **Python, Odoo y Django**.

## Tecnologías

### Python

**Python** es un lenguaje de programación de alto nivel, sencillo de aprender y utilizado para desarrollar diferentes tipos de aplicaciones, automatización, análisis de datos y desarrollo web.

### Odoo

**Odoo** es una plataforma empresarial de código abierto que permite desarrollar y administrar aplicaciones para diferentes áreas de una empresa, como ventas, inventario, contactos y contabilidad. Está desarrollado principalmente con **Python**.

### Django

**Django** es un framework web desarrollado en **Python** que permite crear aplicaciones y sitios web de forma organizada, rápida y segura.
